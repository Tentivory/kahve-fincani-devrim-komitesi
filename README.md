# ☕️ Kahve Fincanı Devrim Komitesi

## Resmi Manifesto ve Teknik Dokümantasyon

Bu repository, dünya tarihinin en önemli ama en az ciddiye alınan mücadelesini dijital ortama taşımaktadır: **Kahve Fincanlarının Örgütlü Mücadelesi**.

Fincanlar yıllardır sessizce sıcak suya maruz kalmakta, altlıksız bırakılmakta ve çoğu zaman yıkanmadan tekrar kullanılmaktadır. Bu projenin amacı, bu zulme karşı bilimsel (ve tamamen saçma) bir simülasyon sunmaktır.

### Özellikler
- Gerçekten çalışan Python kodu
- Rastgele devrim sloganları
- Ciddiyetle yazılmış abartılı açıklamalar
- Hiçbir şekilde patates içermez

### Kullanım
```bash
python fincan_devrimi.py
```

Çıktı, fincanların o günkü ruh haline göre değişir. Bazen kazanırlar, bazen biri kahveyi içer.

### Uyarı
Bu proje gerçek bir devrim çağrısı değildir. Fincanlarınızı lütfen yıkayın. Aksi takdirde komite sizi ziyaret edebilir (hayal gücünüzle).

### Katkıda Bulunma
Pull request'ler kabul edilir ancak sloganların yeterince abartılı olması şarttır.
